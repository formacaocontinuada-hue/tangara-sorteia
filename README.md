# Tangará Sorteia

Bingo e sorteio para os eventos das escolas da rede municipal de Tangará da Serra, com o mascote Tangará.

**Abrir o app:** https://formacaocontinuada-hue.github.io/tangara-sorteia/

No Edge ou no Chrome, clique em **Instalar app** (no topo do app ou na barra de endereço) para criar o atalho no computador. Depois de instalado, funciona sem internet.

- Bingo de 75 bolas com acompanhamento e conferência das 700 cartelas
- Sorteio de números com intervalo livre
- Cartelas para imprimir em PDF, com temas prontos ou a arte da escola
